# 回环候选位姿限制

Scan Context 使用场景描述子的相似度搜索历史帧，默认不按空间距离搜索。
loop_time_gap 是时间排除，sc_max_radius 是描述子的单帧点云半径，不是两个位姿的距离限制。

新增参数（Point-LIO 和 Super-LIO 的 SC-PGO launch 共用 sc_pgo.yaml）：

- loop_max_translation_distance: 15.0，原始前端两个关键帧位置的三维欧氏距离上限，单位米。
- loop_max_rotation_deg: 60.0，两个姿态最短相对旋转角的上限，单位度，范围 0~180。
- 任一参数设为 0 可关闭该项限制。

旋转角等于相对旋转向量的模，而不是两个欧拉角或旋转向量直接相减。例如 yaw 从 +179° 到 -179°，相对旋转只有 2°。
候选超过任一启用的上限就不会进入 ICP，不会添加回环因子，也不会显示已优化回环连线。
通过限制仍须通过 ICP，且完成图优化后才显示连线。拒绝日志给出实际距离和阈值。

使用原始前端位姿，避免之前的 PGO 修正影响候选门限。累计里程计漂移可能导致真实回环被过滤；平移阈值应覆盖预计漂移。
60° 会过滤反向回访的真实回环，需此类回环可设置 180° 或 0。
这些参数启动时读取，修改配置后需重新启动 SC-PGO；重新编译/安装后 source 对应 install/setup.bash。

本次只增加候选位姿门限。当前 ICP 子地图构建仍以共同根位姿放置各帧点云，
并且最大对应距离配置为 150 米；门限不是完整的几何验证修复，重复环境在门限内仍可能误匹配。
